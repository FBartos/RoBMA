# 36 estimates of the effect of household chaos on child executive functions with the mean age and assessment type covariates from a meta-analysis by Andrews et al. (2021)

The data set contains correlation coefficients `r`, standard errors
`se`, executive functioning assessment type `measure`, and the mean age
of the children in each study `age`. The original data set assessed the
effect of household chaos on child executive functions (Andrews et al.
2021) which was used as an example in Bartoš et al. (2022) .

## Usage

``` r
Andrews2021
```

## Format

A data.frame with 4 columns and 36 observations.

## Value

a data.frame.
