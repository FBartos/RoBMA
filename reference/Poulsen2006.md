# 5 studies with a tactile outcome assessment from Poulsen et al. (2006) of the effect of potassium-containing toothpaste on dentine hypersensitivity

The data set contains Cohen's d effect sizes, standard errors, and
labels for 5 studies assessing the tactile outcome from a meta-analysis
of the effect of potassium-containing toothpaste on dentine
hypersensitivity (Poulsen et al. 2006) which was used as an example in
Bartoš et al. (2021) .

## Usage

``` r
Poulsen2006
```

## Format

A data.frame with 3 columns and 5 observations.

## Value

a data.frame.
