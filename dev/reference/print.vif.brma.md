# Print VIF Results

Prints variance inflation factors and optional posterior correlation
matrix.

## Usage

``` r
# S3 method for class 'vif.brma'
print(x, digits = 3, ...)
```

## Arguments

- x:

  a `vif.brma` object

- digits:

  number of decimal places. Defaults to 3.

- ...:

  additional arguments (currently ignored)

## Value

Returns `x` invisibly.
